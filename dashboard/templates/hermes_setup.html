Hermes Agent 接入指南

5 分钟完成配置，让 18 位大师成为你的 AI 对话伙伴

→ 委员会 → AI 对话
环境检查
🐍 Python 3.8+ 检测中…
📦 augur-agents 已安装 检测中…
🔌 augur-mcp 命令可用（Python 3.10+，pip install -e ".[mcp]"） 需手动验证
1
安装 Augur + MCP 依赖
需要 Python 3.10+ 才能使用 MCP 功能。
# 克隆仓库（或用你已有的本地目录） git clone https://github.com/BruceLanLan/augur-next.git && cd augur-next # 安装含 MCP 支持的完整版 pip install -e ".[data,mcp]" # 验证 augur-mcp 命令 augur-mcp --help
2
配置你的 AI 客户端
选择你使用的平台：
Hermes Studio
Claude Desktop
其他 MCP 客户端
编辑 ~/.hermes/config.yaml：
mcp_servers: augur: command: augur-mcp # augur-mcp 须在 PATH 中
重启 Hermes Studio，然后在对话框输入：
/skill augur-buffett "AAPL 值得买吗？PE=32，ROE=55%"
编辑 ~/Library/Application Support/Claude/claude_desktop_config.json：
{ "mcpServers": { "augur": { "command": "augur-mcp" } } }
保存后重启 Claude Desktop，MCP 工具会自动出现在工具列表。
任何支持 MCP stdio 传输的客户端：
# 启动方式：stdio 传输 command: augur-mcp # 工具会自动注册为： mcp_augur_analyze, mcp_augur_consensus, mcp_augur_committee, mcp_augur_debate, mcp_augur_fetch, mcp_augur_sentiment, mcp_augur_list_personas, mcp_augur_configure
3
开始对话
在 Hermes Studio 中加载任意大师 Skill，然后直接提问：
/skill augur-buffett
巴菲特 · 价值护城河
/skill augur-duan-yongping
段永平 · 本分集中
/skill augur-dalio
达利欧 · 全天候宏观
/skill augur-cathie-wood
凯西伍德 · 颠覆创新
/skill augur-zhang-lei
张磊 · 结构性长期
/skill augur-committee
委员会主席 · 多Agent协调
4
召开投资委员会
有两种方式召开委员会：
方式 A：通过 Hermes Skill（推荐）
/skill augur-committee "中国价值委员会：段永平、张磊、李录、但斌，讨论腾讯00700.HK的投资价值"
方式 B：通过 Dashboard
在本页侧边栏点击「投资委员会」，选择大师，输入标的和问题。
→ 打开委员会页面
常见问题
augur-mcp: command not found
运行 pip install -e ".[mcp]" 安装 MCP 支持（需要 Python 3.10+）。
如果仍报错，检查 pip show augur-agents | grep Location，将对应 bin 目录加入 PATH。
MCP 工具出现但调用失败
实时数据需要 yfinance：pip install -e ".[data]"
如果只需要评分（不需要实时价格），传入手动指标即可：
mcp_augur_analyze(ticker="AAPL", pe=32, roe=0.55)
/skill augur-buffett 没有反应
确认 Hermes 的 skills.external_dirs 指向 augur-next 的 skills/ 目录：
skills:
  external_dirs:
    - /path/to/augur-next/skills
