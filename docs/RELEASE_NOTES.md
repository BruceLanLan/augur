# Augur 本次更新说明

> 面向用户的功能说明（非技术变更日志，技术细节见 [CHANGELOG.md](../CHANGELOG.md)）。

## 这次更新解决了什么问题

过去 Augur 是一个"问答型"的投资分析工具：你打开 Dashboard，输入股票代码，18 位投资大师给你一份共识报告。这很有用，但有两个明显的短板：

1. **每个人看盘的习惯不一样，但 Augur 只有一种样子。** 短线交易者想要的首页布局，和做深度研究的人想要的完全不同；有人只信任价值派 4 位大师，有人想要全部 18 位都参与共识——过去这些都没法保存和切换。
2. **接入 AI Agent 之后，Agent 只会"分析"，不懂"你"。** 你可以让 Claude/Hermes 调用 Augur 的分析工具，但 Agent 完全不知道你在 Dashboard 上配置了什么——它没法读取你的布局偏好，也没法替你调整。Agent 和你的终端是两个互不相通的世界。

这次更新就是为了解决这两个问题，方向是：**把 Augur 变成一个用户能高度定制的 Bloomberg 终端，同时让 AI Agent 真正能"接管"这个终端，而不只是在旁边聊天。**

## 新增功能

### 1. 终端工作区（Terminal Workspace）—— 像 Bloomberg 一样定制你的终端

- **布局预设**：analyst（分析师，默认）/ trader（交易员）/ committee（委员会）/ minimal（极简），一键切换默认首页、隐藏导航栏、是否显示实时价格滚动条。
- **多套配置（Profile）**：可以保存多套命名配置，比如"白天看盘""周末深度研究"，随时切换，互不覆盖。
- **只看你信任的大师**：可以只启用一部分投资大师参与共识计算（比如只用 4 位价值派大师），系统会自动重新分配权重，而不是简单地把权重平分掉——这是容易被忽略但很关键的一点，否则"只选 4 个人"和"选全部 18 个人但只看 4 个人的意见"在计算上会是两回事。
- **委员会预设绑定到配置**：切换配置时，默认委员会组合也会一起切换。
- 配置保存在你本机的 `~/.augur/workspace.yaml`，支持导出/导入，换机器也能带走。

操作位置：Dashboard → 设置（Settings）页。

### 2. AI Agent 现在能读懂、也能修改你的终端

这是这次更新里最重要的一块。如果你通过 Claude Desktop、Hermes Studio 或任何支持 MCP 协议的客户端接入 Augur，现在 Agent 可以：

- **读取**你当前的终端布局、启用了哪些大师、用的是哪套委员会预设；
- **代你修改**——比如你直接跟 Agent 说"帮我切到交易员模式，只看价值派的意见"，Agent 可以直接帮你把配置改好，不需要你手动点 Dashboard；
- **列出、创建、切换、删除**你保存的多套配置。

换句话说，以前 Agent 只是一个"挂在 Augur 外面"的聊天助手，现在它能感知并操作你的实际工作环境——这正是"agentic"（具备自主行动能力）和单纯"chat"之间的区别。

### 3. 一条指令跑完整套分析流程（`augur_workflow`）

以前如果你想要"先抓实时数据，再跑全员分析，再算共识，再开委员会"，需要分四步分别调用。现在一条命令/一次 Agent 调用就能串联起来：

```bash
augur workflow NVDA --steps fetch,analyze,consensus,committee
```

也可以限定只让你启用的那几位大师参与（自动和终端工作区的"启用大师"配置联动）。

### 4. 共识计算引擎增强

在共识打分背后，新增了一套更细致的计算模块：行业权重矩阵、市场周期（regime）识别与路由、概率校准、滚动 IC（信息系数）评估、宏观因子、风险管理。其中一个值得单独说明的点：

- 系统内部有一个"中位数混合"机制，会把最终分数往全部大师的中位数方向拉一部分，避免极端意见过度影响结果。过去这个混合比例是固定写死的 50%，且不太透明。这次把它做成了可调参数（`consensus.meta_model_weight`），默认还是 50%，但你可以把它调到 0（完全不混合）到 1（完全用中位数）之间的任意值。

## 这次更新修复了什么

代码审查过程中发现并修复了几个不影响日常使用、但会让结果不够准确/不够稳的小问题：

- 某些情况下"分析超时"的提示从未真正触发过（被更外层的异常处理兜住了，功能不受影响，只是报错信息不准确）。
- 后台一个缓存模块存在并发读写风险，已加锁修复。
- 几份接入文档里写的"工具数量"是旧版本的数字（9个/10个），已经更新为当前实际的 13 个，并补全了缺失的工具说明。
