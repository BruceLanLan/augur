# 18 位投资大师外貌特征（基于真实照片核实）

## 需要修正的头像

根据搜索到的真实照片，以下头像特征需要修正：

1. **Peter Lynch** — 修正：白发（不是卷发蓬松），戴圆框/椭圆框眼镜，瘦长脸，穿深色西装打花纹领带。之前描述为"不戴眼镜"是错误的。
2. **Howard Marks** — 修正：戴浅色透明框眼镜（非常标志性），灰白短发，瘦脸，穿深色西装红领带。之前描述为"不戴眼镜"是错误的。
3. **Philip Fisher** — 修正：戴黑框眼镜（非常标志性），深色头发向后梳，1950年代风格，穿西装打领带。之前描述为"不戴眼镜"是错误的。
4. **Leopold Aschenbrenner** — 修正：金色/浅棕色中长卷发（非常标志性），白皮肤，年轻（20多岁），穿浅色休闲装（白色高领毛衣/浅色衬衫）。之前描述为"深色短发"是错误的。
5. **Peter Thiel** — 修正：短发略微后退，不戴眼镜是对的，但头发颜色偏浅棕/沙色（不是深色），穿黑色T恤或深色休闲装。
6. **段永平** — 修正：不秃，头发正常偏短，不戴眼镜（或偶尔戴），圆脸偏胖，穿白色T恤/polo衫很休闲。之前描述"微秃+戴眼镜"需要修正为"不戴眼镜，头发正常"。
7. **张磊** — 修正：戴眼镜是对的，但是方框眼镜（不是圆框），头发整齐偏短，穿深色西装或灰色西装。
8. **李录** — 修正：60多岁，白发/灰白发（不是黑发），不戴眼镜，瘦脸，穿深色西装打蓝色领带。之前描述"短黑发"需要修正为"灰白发"。
9. **但斌** — 修正：戴眼镜（方框），头发整齐偏短，圆脸，穿深色西装打领带。之前描述"不戴眼镜"是错误的。
10. **Cathie Wood** — 确认：深棕色长直发（有时略带波浪），戴深色方框眼镜，穿黑色职业装。描述基本正确。
