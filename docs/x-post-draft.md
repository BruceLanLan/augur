# X Post Draft (Bruce Style)

最近把之前写着玩的投资 Agent 系统 Augur 彻底翻新了一遍。

其实市面上不缺帮你看财报的 AI，也不缺帮你总结电话会的工具。真正重要的问题不是“AI 能不能看懂数据”，而是“AI 看完数据后，敢不敢下注，用什么逻辑下注”。

如果只把 Augur 理解成一个股票分析工具，其实低估了它。它不是单纯的总结器，更像是一层基于大师智慧的投资风控系统。

在真实的交易环境里，散户最容易犯的错，是单线思维：因为某个利好，就忽略了估值；因为估值便宜，就忽略了商业模式的崩溃。

所以 Augur 的核心机制不是“让一个最聪明的模型给你答案”，而是“强制让 18 种完全不同的投资哲学同时运转”。

```text
+----------------+------------------------------+
| 投资流派       | 核心切入点                   |
+----------------+------------------------------+
| 巴菲特/芒格    | 护城河、ROE、安全边际        |
| 达利欧/索罗斯  | 宏观周期、流动性、反射性     |
| 彼得蒂尔/木头姐| 0到1垄断、TAM扩张、指数增长  |
| 段永平/李录    | 商业模式本分、中国资产定价   |
+----------------+------------------------------+
```

当你输入 NVDA，木头姐会看到算力基础设施的指数级爆发，给出 8.5 分；但霍华德·马克斯会看到极度拥挤的交易情绪和透支的估值，给出 4.5 分。

这改变了什么工作方式？

从“向 AI 寻求一个确定性答案”推进到了“看 AI 之间如何辩论”。最后通过 Kelly 公式，把这些带着各自偏见的分数，收敛成一个带有置信度和仓位建议的共识信号。

为了让这套系统真正能用，这次更新彻底重写了 UI，做了一套 Bloomberg 风格的暗色 Dashboard。不仅是好看了，而是让数据密度和决策信号的呈现更符合交易者的直觉。

同时把底层重构成了 MCP Server，现在你可以直接在 Claude Desktop 或者 Hermes 里一键唤醒这 18 位老头（和老太太）。

我自己也付过代价：曾经在某些票上因为单一视角的盲目自信，交过不少学费。人脑很难同时保持极度乐观的成长想象力和极度悲观的风险厌恶，但系统可以。

工具的终局，是维护秩序。Augur 就是一个帮你对冲人性弱点的秩序系统。
